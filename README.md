# WA Web — свой WhatsApp Web на Baileys

Веб-клиент WhatsApp на базе [Baileys](https://github.com/WhiskeySockets/Baileys) (v7) с двумя режимами приватности:

- **👻 Невидимка** — выключает статус «В сети». Клиент сообщает WhatsApp, что вы `unavailable`, и никогда не отправляет «печатает…».
- **🙈 Без прочтения** — выключает отчёты о прочтении. Открытие чата не ставит синие галочки, голосовые не отмечаются прослушанными. Прочитать вручную можно кнопкой «Прочитать (N)» в шапке чата или через контекстное меню чата.

Оба режима переключаются в **Настройках** (шестерёнка) и включены по умолчанию.

## Возможности

- Вход по **QR-коду** или **8-значному коду** по номеру телефона
- Синхронизация **истории сообщений** при входе (клиент представляется десктопом и получает полную историю), а при прокрутке вверх старые сообщения дозапрашиваются с телефона
- Личные чаты и **группы** (участники, админы, описание), архив, закреплённые, без звука, фильтр «Непрочитанные», поиск
- **Фото, видео, кружочки, голосовые, аудио, документы, стикеры**, геолокация, контакты, опросы, системные сообщения групп
- Цитаты/ответы, реакции, пересланные, отредактированные и удалённые сообщения, статусы доставки ✓ / ✓✓ / синие ✓✓
- Отправка текста, ответы, реакции, удаление у всех, отправка файлов (кнопка, перетаскивание, вставка из буфера), **запись голосовых** из браузера
- Аватарки, «в сети / печатает / был(а)» у собеседников (в режиме невидимки WhatsApp может их не присылать)
- Светлая и тёмная тема, мобильная вёрстка
- Всё хранится локально в SQLite (`data/`), медиа скачивается по требованию и кэшируется

## Запуск

Нужен **Node.js 22.13+** (используется встроенный `node:sqlite`). Для отправки голосовых нужен **ffmpeg** с libopus. Без него всё остальное работает.

```bash
npm install
npm start
# открыть http://localhost:3000
```

Переменные окружения:

| Переменная     | По умолчанию | Описание |
|----------------|--------------|----------|
| `PORT`         | `3000`       | Порт веб-сервера |
| `HOST`         | `0.0.0.0`    | Адрес прослушивания |
| `APP_PASSWORD` | —            | Пароль на веб-интерфейс. **Обязательно задайте, если сервер доступен из интернета**: иначе любой, кто откроет страницу, прочитает вашу переписку |
| `DATA_DIR`     | `./data`     | Папка с сессией, базой и медиа |
| `LOG_LEVEL`    | `info`       | Уровень логов pino |

Запись голосовых в браузере работает только по HTTPS или на `localhost`.

### Docker

```bash
docker build -t wa-web .
docker run -d -p 3000:3000 -e APP_PASSWORD=секрет -v $(pwd)/data:/app/data wa-web
```

## Как работают режимы приватности

**«В сети».** Baileys по умолчанию при подключении объявляет присутствие `available`. Здесь сокет создаётся с `markOnlineOnConnect: false`, и сервер сам решает, что отправлять:

- режим выключен → всегда `unavailable`, индикатор «печатает…» не отправляется;
- режим включён → `available` только пока открыта и активна хотя бы одна вкладка (как в настоящем WhatsApp Web), при сворачивании вкладки → `unavailable`.

**«Прочтено».** Baileys сам отправляет только квитанции о *доставке* (серые ✓✓). Синие галочки уходят лишь при вызове `readMessages`, а его клиент вызывает только если режим включён и чат открыт в активной вкладке. Отметка «прослушано» для голосовых работает так же.

Ограничения, которые не обойти со стороны клиента:

- если на телефоне открыт WhatsApp, вы будете «в сети» из-за телефона;
- режим этого клиента **не меняет** настройку аккаунта «Отчёты о прочтении», поэтому чужие синие галочки вы продолжаете видеть;
- чтобы видеть «в сети» и «печатает» собеседников, WhatsApp обычно требует, чтобы вы сами были `available`.

## Структура

```
src/server.js     — Express + Socket.IO, раздача медиа и аватарок, пароль
src/wa.js         — сессия Baileys, обработка событий, режимы приватности, отправка
src/db.js         — хранилище SQLite (чаты, сообщения, реакции, контакты, группы, LID↔номер)
src/serialize.js  — разбор сообщений WhatsApp в формат для интерфейса
public/           — интерфейс (чистый JS, без сборки)
```

## Важно

Baileys — неофициальная библиотека. Использование неофициальных клиентов нарушает условия WhatsApp и может привести к блокировке номера. Не используйте её для рассылок. Папка `data/auth` содержит ключи вашей сессии, никому её не передавайте.
