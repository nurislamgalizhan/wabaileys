# WA Web — свой WhatsApp Web на Baileys

Веб-клиент WhatsApp на базе [Baileys](https://github.com/WhiskeySockets/Baileys) (v7): переписка, медиа, группы и набор функций, которых нет в обычном WhatsApp Web.

## Режимы приватности

- **👻 Невидимка** — выключает статус «В сети». Клиент сообщает WhatsApp, что вы `unavailable`, и не отправляет «печатает…».
- **🙈 Без прочтения** — выключает отчёты о прочтении. Открытие чата не ставит синие галочки, голосовые не отмечаются прослушанными. Прочитать вручную можно кнопкой «Прочитать (N)» в шапке чата.
- **Незаметный просмотр статусов** — статусы видны, а вы не попадаете в список просмотревших.
- **Сохранение удалённых сообщений** — если собеседник удалит сообщение у всех, у вас останутся его текст и медиа с пометкой «Удалено отправителем». Для изменённых сообщений сохраняется история правок (нажмите «изм.»).

Всё это включается в **Настройках** отдельно для каждого аккаунта. По умолчанию: невидимка и без прочтения — включены, удалённые сохраняются, статусы смотрятся незаметно.

## Возможности

**Вход и аккаунты**
- Вход по QR-коду или 8-значному коду по номеру телефона
- **Несколько аккаунтов WhatsApp** в одном интерфейсе: переключение по аватарке слева сверху, у каждого свои чаты, настройки и автоответчик
- **Название устройства** в «Связанных устройствах» на телефоне (задаётся на экране входа до привязки)
- Сессия хранится на сервере: после перезапуска входить заново не нужно

**Переписка**
- Синхронизация истории при входе, догрузка старых сообщений с телефона при прокрутке
- Фото, видео, кружочки, голосовые, аудио, документы, стикеры, геолокация, контакты, опросы
- Ответы, реакции, пересылка, редактирование своих сообщений (первые 15 минут), удаление у себя и у всех, избранное ⭐
- Отправка файлов (кнопка, перетаскивание, вставка), запись голосовых
- **Поиск по всей переписке** с подсветкой и переходом к найденному сообщению
- **Отложенные сообщения** — отправит сервер в нужное время, даже если браузер закрыт

**Чаты и группы**
- Архив, закрепление, «без звука», очистка и удаление чатов, блокировка контактов
- Создание групп, вступление по ссылке, для админов — название, описание, фото, участники (добавить, удалить, назначить админом), ссылка-приглашение, права участников
- Профиль собеседника: «Сведения», бизнес-профиль

**Профиль и приватность аккаунта**
- Смена имени, «Сведений», фото профиля
- Настройки приватности WhatsApp: кто видит «был(а)», «в сети», фото, сведения; отчёты о прочтении аккаунта; кто может добавлять в группы, звонить, писать; исчезающие сообщения по умолчанию

**Автоматизация**
- **Автоответчик** с правилами: по словам, точному совпадению, регулярному выражению или на любое сообщение; личные или групповые чаты; «не чаще раза в N минут»; «только когда клиент не открыт»; задержка; ответ цитатой
- **Ответы через Claude (ИИ)**: модель отвечает с учётом последних 30 сообщений чата по вашей инструкции («Я фотограф, цены такие-то…»)
- **Автоотклонение звонков** с ответным сообщением и журнал звонков (принимать звонки Baileys не умеет)
- **HTTP API** и **вебхуки** для интеграции с CRM, n8n, ботами

**Интерфейс**
- Светлая и тёмная темы, мобильная версия: долгое нажатие открывает меню, свайп отвечает на сообщение, кнопка «Назад» закрывает экраны
- Установка как приложение (PWA)

## Запуск

Нужен **Node.js 22.13+** (используется встроенный `node:sqlite`). Для отправки голосовых нужен **ffmpeg** с libopus.

```bash
npm install
APP_PASSWORD=ваш_пароль npm start
# открыть http://localhost:3000
```

| Переменная          | По умолчанию | Описание |
|---------------------|--------------|----------|
| `PORT`              | `3000`       | Порт веб-сервера |
| `HOST`              | `0.0.0.0`    | Адрес прослушивания |
| `APP_PASSWORD`      | —            | Пароль на веб-интерфейс. **Обязательно задайте, если сервер доступен из интернета** |
| `DATA_DIR`          | `./data`     | Папка с сессиями, базой и медиа |
| `ANTHROPIC_API_KEY` | —            | Ключ Claude API для ИИ-ответов (можно задать и в интерфейсе автоответчика) |
| `LOG_LEVEL`         | `info`       | Уровень логов pino |

Запись голосовых в браузере работает только по HTTPS или на `localhost`.

```bash
docker build -t wa-web .
docker run -d -p 3000:3000 -e APP_PASSWORD=секрет -v $(pwd)/data:/app/data wa-web
```

## HTTP API

Токен — в меню ⋮ → «API и вебхуки». Передаётся заголовком `Authorization: Bearer <токен>`.

```bash
GET  /api/v1/accounts                          # аккаунты и их состояние
GET  /api/v1/<аккаунт>/chats                   # список чатов
GET  /api/v1/<аккаунт>/chats/<chatId>/messages # сообщения (?before=<ts>&limit=50)
GET  /api/v1/<аккаунт>/search?q=слово          # поиск по переписке
POST /api/v1/<аккаунт>/messages                # {"to":"77011234567","text":"Привет", "at":"2026-12-31T10:00:00+05:00"}
```

Идентификатор первого аккаунта — `main`. Вебхук получает `POST {"event":"message","account":"…","message":{…}}` на каждое новое сообщение. Заголовок `X-Signature` — HMAC-SHA256 тела с токеном API в качестве ключа.

## Ответы через Claude

В правиле автоответчика отметьте «Отвечать с помощью Claude» и напишите инструкцию. По умолчанию используется модель `claude-opus-5-5` с низким уровнем рассуждений: этого достаточно для коротких ответов в чате. Модель можно сменить в настройках автоответчика. Для моделей Claude Opus 5.5, Opus 5, Fable 5.1 и Sonnet 5.5 включён серверный резерв: если модель откажется отвечать, запрос автоматически выполнит другая модель. Каждый ответ — это платный запрос к Claude API.

## Как работают режимы приватности

**«В сети».** Сокет создаётся с `markOnlineOnConnect: false`, и сервер сам решает, что отправлять: при выключенном режиме — всегда `unavailable`, при включённом — `available`, только пока открыта и активна вкладка.

**«Прочтено».** Baileys сам отправляет только квитанции о доставке (серые ✓✓). Синие галочки уходят лишь при вызове `readMessages`, а клиент вызывает его только при включённом режиме и открытом чате. Так же устроены «прослушано» и просмотр статусов.

Ограничения со стороны WhatsApp:
- если на телефоне открыт WhatsApp, вы будете «в сети» из-за телефона;
- режимы клиента не меняют настройки аккаунта, поэтому чужие синие галочки вы продолжаете видеть. Настройки аккаунта меняются отдельно, в разделе «Приватность аккаунта WhatsApp»;
- сохраняются только те удалённые сообщения, которые пришли, пока клиент был подключён. Медиа «на один просмотр» WhatsApp на связанные устройства не присылает;
- если телефон не выходит в интернет около 14 дней, WhatsApp отвязывает все связанные устройства.

## Структура

```
src/server.js     — Express + Socket.IO, медиа, HTTP API, пароль
src/accounts.js   — несколько аккаунтов, планировщик отложенных сообщений
src/wa.js         — сессия Baileys: события, приватность, отправка, группы, профиль, статусы, звонки
src/bot.js        — автоответчик, ответы через Claude, вебхуки
src/db.js         — SQLite: чаты, сообщения, поиск (FTS5), реакции, контакты, группы, правила, отложенные
src/serialize.js  — разбор сообщений WhatsApp в формат для интерфейса
public/           — интерфейс без сборки: app.js (ядро), features.js (доп. экраны)
```

## Важно

Baileys — неофициальная библиотека. Неофициальные клиенты нарушают условия WhatsApp, за них могут заблокировать номер, особенно при массовых рассылках и агрессивных автоответах. Папки `data/auth` и `data/accounts/*/auth` содержат ключи сессий — никому их не передавайте.
